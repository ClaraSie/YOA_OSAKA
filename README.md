# Osaka 2026 GitHub Pages

Static multi-page travel site.

## Structure
- `index.html` — landing page / trip overview
- `days/day1.html` ... `days/day6.html` — daily itinerary pages
- `shopping.html` — shopping list
- `assets/css/styles.css` — shared design tokens + layout + Vaporwave UI
- `assets/js/main.js` — reveal animation + trip countdown

## GitHub Pages
Push this folder to the repository root, then enable:
Settings → Pages → Deploy from a branch → `main` / `(root)`.

No build step is required.
